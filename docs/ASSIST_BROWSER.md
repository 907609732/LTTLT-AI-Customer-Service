## 本轮调整

- 现有 Electron 依赖升级为 npm 实际可取得的 43.8.9（Chromium 150.0.7871.250），本机官方运行时位于 `C:/Users/90760/AppData/Local/LingtuRuntime/electron-43.8.9/`。
- `store-browser.ts` 在页面导航前统一 Session 和 WebContents 的标识，使用真实内核版本。仅作用于当前工作区所属店铺分区，保留原登录分区。
- 关闭辅助中心停止采集和提醒，保留空闲后台页；重新打开复用。退出工作区时仍销毁。取消正在执行的读取时销毁相应页面以终止旧任务。
- 验证入口复用实际受阻的采集窗口，避免用户在另一个页面验证后采集页仍然受阻。正常事项处理页保持独立，避免采集切走用户表单。
- 遇到验证码暂停店铺自动刷新；没有自动求解、绕过验证或反复重试。保留 sandbox、contextIsolation，不修改自动化指纹，不伪造内核版本。
- 已移除本轮临时页面结构探针和调试文件写入逻辑。

官方依据：[Session](https://www.electronjs.org/docs/latest/api/session)、[BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window/)、[版本列表](https://releases.electronjs.org/?channel=stable)。Session 默认标识不会追溯更新已有 WebContents，因此两处都设置。
