## 代码结构

- `electron/main.cjs`、`electron/preload.cjs`：安全 Electron Shell
- `src/components/Topbar.tsx`、`Sidebar.tsx`：公共应用布局
- `src/pages/*`：已实现页面
- `shared/snapshot.mjs`：本地设计快照校验
- `plugins/figma-local-export/`：只读导出插件
- `scripts/import-design.mjs`：快照导入拆分
- `docs/figma-map.json`：UX 路由映射与待填 Figma nodeId

## 继续开发的顺序

1. 在 Figma 中运行本地导出插件，优先导出 UX01、UX04、UX11 三张正式画板。
2. 比对真实画板的尺寸、颜色、间距和资源，替换当前根据旧 HTML 原型实现的页面。
3. 完成配置中心共用控件，逐页补齐 UX08–UX25；五个滚动续页合并到对应的三个主页面。
4. 实现 AI 辅助中心工作台 UX26–UX32（会话列表、编辑器、各状态、确认关闭）。
5. 建立 Mock Service → API Contract → 真正的平台数据接入的明确界限；先测试真实权限与回执，再启用发送/批量动作。
6. 完善 Electron 原生自动化、签名、更新、NSIS 构建与端到端回归。

## 数据保护

本项目仓库为私有；Figma JSON 快照、客户聊天记录、登录状态和本机环境变量保持在本地，不推送远程。导入的快照会在 Electron 的 userData 目录中保存副本，使用者需自行管理备份和权限。全部真实平台接口目前禁用。
