原始设计快照保存在Git忽略目录。未写入账号凭据或真实客户聊天；设计示例不作为生产数据。Electron保留sandbox/contextIsolation及来源受限IPC，不开放渲染器Node权限。非ASCII项目目录使用同版本ASCII运行时镜像；窗口可执行文件名为LingtuCustomerService.exe。
