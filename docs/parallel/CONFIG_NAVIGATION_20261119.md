# 配置中心侧栏菜单压缩修复

原因：旧更新入口的 `flex-basis:100%` 在纵向侧栏中占据整屏高度，菜单被挤到 16px；虽已在 1.0.75 修正共享更新组件，侧栏仍依赖所有子项的 flex 布局。改为显式 Grid 行：标题、剩余高度菜单、回复监控、更新入口、版本。菜单 `min-height:0`，低窗口内滚动，底部入口按实际内容占高。

验证（遵照用户本次明确要求，不打包、不构建）：

- Vite 源码热更新浏览器实测，模拟旧入口 flex-basis 条件复现菜单仅 16px；修复后同一条件在 1440×920 为 679px，更新入口 26px，按钮约 33px。
- 1280×720、1160×720、1440×600：按钮高度不变，短窗口仅菜单区滚动，菜单与底部入口无重叠；客服质检和店铺与商品点击导航正常。
- 改动 Vue 文件 ESLint、Prettier、git diff --check 通过；配置中心/旧训练路由相关 2 文件 4 项回归通过。
