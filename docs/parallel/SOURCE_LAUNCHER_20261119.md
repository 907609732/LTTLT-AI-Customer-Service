# 不构建的手动源码入口（1.0.79）

用户要求新增供其手动双击的入口，不构建、不打包，保留原账号与知识数据。本批不自动运行入口。

- 根目录 `启动源码（不构建）.bat` → `scripts/start-source.ps1 -NoBuild` → `scripts/start-source-live.ps1`。复用原控制台生命周期 Job，原入口默认构建行为不变。
