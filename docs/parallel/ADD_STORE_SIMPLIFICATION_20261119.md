# 添加店铺简化与闲鱼店名回填

用户要求删除闲鱼内嵌机制提示及添加弹窗的本机模拟入口，不再手填店名，登录后直接识别。沿用不构建、不打包的源码维护方式。

## 改动

- 添加弹窗移除闲鱼机制提示、名称表单和模拟入口，平台可用性、创建失败提示、只重试打开及工作区隔离保留。
- 闲鱼以注册表既有占位名“闲鱼店铺”添加，扫码认证后改走后端完整 open-store 流程，经 SimStoreManager 回填登录名/卖家 ID 并刷新快照。此前回调直接调用厂商 manager，绕过外层身份同步。已有自定义名称、账号变化停 AI 的规则不变，不改 vendor。
- 独立审查发现模拟客服台仍指向被移除的添加入口，已删除失效空态按钮/步骤并修正服务端本机提示；已有模拟数据、模拟客服台和隔离测试能力保留。

## 验证与边界

- 修改测试后先确认 2 项失败：闲鱼名称输入仍存在、机制说明仍显示。修复后 add-shop 与 simulator 两文件共 22 项通过。
- Vue 与 Electron noEmit 类型检查、改动 ESLint、Prettier 和 git diff --check 通过。
- 一次独立只读审查；唯一发现的模拟页失效引导已处理。
- 不新增接口、依赖、IPC 或持久化字段，不新建真实店铺、不登录/发送/开启 AI，不构建、不打包。
- 等待整合聊天统一版本、主线合入及本机添加弹窗查看。前端可经 Vite 显示；Electron 回调修改属于主进程源码，复用旧 dist 运行时不会生效，不以源码已修改代替真实扫码回填验收。主进程生效待用户允许的后续源码编译批次；本轮不突破不构建约束。
