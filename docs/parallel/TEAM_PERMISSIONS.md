# 团队权限实现计划与接入边界

范围：独立团队租户；owner/admin/agent/auditor 固定角色；已有账号定向邀请和本人接受；团队店铺登记与逐成员授权；团队工单登记、分配、状态、跟进和审计。店铺授权只允许访问本软件团队业务记录，不代表电商平台登录或后台权限。

复用现有 Gin、GORM（MIT）及 SQLite 测试驱动；保留服务端已有 AGPL 许可。已检索 Casbin/GORM（Apache-2.0，维护活跃），其动态策略与额外迁移超过本轮四种固定角色需求，不引入新生产依赖。所有写入在事务中争用团队 revision，权限和数据更新在同一事务；版本冲突明确返回，不覆盖并行修改。

文件边界：新增 server/overlay/lingtuteam/\*、lingtuhost/team.go；account/quality 的团队契约、服务、组件；独立测试和本交接。公共路由、IPC、主进程 token 协议不抢改。注册/IPC缺口记录精确接入步骤。禁止把本机原有工单或平台登录静默迁入团队。

验证：先独立 Go 原生领域安全测试，再 HTTP 权限测试，Vue 服务/本机提示增量测试。隔离 SQLite；不请求生产，不发送真实买家消息。
