# 灵兔客服 v0.4.2

- 模型设置新增 DeepSeek、通义千问厂商选择，自动填充官方接口及默认模型，只需粘贴 API Key。
- 新增官方密钥页面入口，通过本地浏览器登录获取密钥。
- 连接测试成功后才保存配置；失败保留原设置，并显示可操作的中文提示。
- 保留高级设置和转人工关键词；密钥继续使用系统加密存储。
- 切换厂商需输入对应密钥，防止跨厂商误用；防止双窗口并发保存导致接口与密钥错配。

千问默认百炼北京地域，其他地域或专属业务空间可在高级设置填写官方接口。

更新方式：在旧版点击“检测更新”，发现新版本后打开 GitHub 下载页下载安装。当前不支持后台自动下载安装。

发布不包含工作区中同时进行的首页及转人工配置中心重构。
