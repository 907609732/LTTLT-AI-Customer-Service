# 管理后台：账号、用量与语言

用户已授权直接沿用灵兔风格开发，无需再次确认布局。

## 范围

- 将概览、模型配置、账号管理、用量记录、登录方式、试用设置放入始终可见的导航。
- 列出所有未删除的原生账号，包含尚未登录客户端的管理员；只读查询不发放额度。额度调整保留管理员安全验证、原因和审计。
- 按账号汇总客户端请求次数、成功/失败/待核查、输入/输出/总词元及最近使用时间，支持查看指定账号的明细和分页。
- 明确区分上游实际返回的用量和未知用量，不将中继估算值当作实测；模型连接检测不计入客户端用量。
- 默认中文，提供中文与英文切换，持久保存语言偏好；覆盖本页、状态、错误及原生安全验证弹窗。模型名称、应用标识、回调地址等技术值保持原值。
- 保留模型密钥的内存草稿与保密边界，不读取现有明文密钥、不通过浏览器或客户端下发密钥。

## 复用

沿用已锁定的 New API、现有 i18next、原生表格/标签页/安全验证和 GORM，不新增重型管理模板。保留 AGPL 来源链接。

## 验证与交付

1. 后端测试覆盖所有账号只读展示、明确授权、汇总分页/筛选及用量来源；运行三种数据库的 CI。
2. 前端测试覆盖导航可发现、语言切换与持久化、账号筛选、未知用量与草稿保留；核对运行时翻译命名空间。
3. 独立审查、针对性测试、类型检查及同次 CI 构建。
4. 下载同次服务端和页面产物，备份数据库及配置，切换独立发布目录，验证页面与受保护 API。
5. 同步境外页面构建；自定义域名地区 DNS/TLS 未验收部分明确保留为未完成，不冒充完整分流。
