# 当前店铺知识操作与导入学习分离

**用户目标：** 导入与学习分别呈现；导出及备份/恢复明确且实际限于当前店铺，界面保持四个主要入口。当前工作树已隔离，复用已有Vue/Element Plus/SQLite备份与工作区维护能力，无新依赖。

## 设计

- 导入仅平台商品、归档聊天、资料文件。学习通用资料放通用问答内容区，沿用估算、确认及审核；商品在各自卡片学习。
- 导出/备份菜单显示当前店名。工具栏导出本店全部问答，详情单商品导出保持原逻辑；文件名与完成提示包含店名。
- 新增真正store备份范围，保留本店绑定、问答、历史、审核及必要附件/来源闭包。共享商品/模板不能被恢复操作跨店覆盖。原件完整文件可能包含其他商品行，在恢复预览披露；这不意味着允许覆盖他店。
- 本店恢复只接受同店store包，不能把全库/family包伪装成本店恢复。原高级完整恢复入口放设置高级区，保留旧备份兼容。
- 同款/全库旧API保持兼容，新请求可选storeId。恢复继续由工作区所有者停服务，绑定预览token、版本、指纹，暂存替换及回滚；不恢复运行中的付费任务或旧AI批准。
