# OCR＋视觉商品学习接入

用户已选择并授权实施OCR提取文字、视觉模型理解图片、仅生成待审核知识，并处理米配匠6件实店商品。复用现有平台图片资产、1400像素分块、模型端口、原图依据与学习任务，不更改发送或发布流程。

- 本机OCR复用微软Windows.Media.Ocr API（已安装简体中文），通过系统Windows PowerShell5调用，无额外算法/模型依赖。检索过Akronae/windows-media-ocr及CLI，未发现明确许可证且包装无取消/超时，故不引入其二进制或代码。PaddleOCR需额外模型/运行环境，本机当前无需新增。
- 固定受限识别动作只允许当前店铺已保存图片来源；不接受任意路径/URL/命令。原图先沿用现有分块，结果按资产/引擎版本缓存并保留原图引用，店铺/来源变化拒绝晚到结果。
- 学习在原图输入之外附上OCR转写作为不可信参考；保留视觉依据验证与人工审核，不把OCR文本冒充已核对事实。文字过长明确省略辅助OCR而保留完整分块图，不静默截断原始结果。
- 托管视觉沿用现有通义模型授权，不能把文字模型伪装成视觉，不能绕过服务端权限。实际模型来源等待用户选择；先完成不依赖该选择的OCR接入。
- 定向RED/GREEN、类型/lint、真实OCR最小验证、独立复核后升版1.0.13并打开。只有真实视觉模型可用后才执行6件学习；失败保留具体原因，不自动重放不确定付费请求。
