# AI服务接口（1.0.9）

用户已选择查询＋采集＋草稿；删除/发布/发送仍只能在原软件确认。

复用已有业务服务与知识管线，不透传business:execute或任意SQL/路径。标准MCP stdio连接器使用官方TypeScript SDK（Apache-2.0，2.4.0，Node>=20），通过主进程持有的本机HTTP入口调用固定工具。入口仅监听127.0.0.1随机端口，每次运行产生新令牌，令牌只写当前用户资料目录，不进入模型结果/日志。拒绝Origin、错误Host、无令牌、超大请求和非白名单操作。

首批工具：状态、店铺列表、打开已有店铺、知识摘要、商品/知识/任务分页查询、读取当前店铺后台目录、按已验证目录范围启动采集、保存本店待审核草稿。查询绑定workspaceId，切换账号或清除重建后旧请求/晚到结果失效。写操作需要requestId防止同进程重复执行，不自动重试网络失败；不提供学习付费模型、删除、发布、发送、凭据或通用执行接口。
