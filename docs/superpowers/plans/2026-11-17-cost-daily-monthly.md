# 人民币日月报表设计及实施计划

目标：正式后台立即可见有依据的估算金额，支持北京时间自然日及自然月查看。根因已复现：164 条历史无快照；保存价格不修改历史，estimateCNY 忽略 rates，UI 将未计价小计显示为 0。

方案：沿用现有整数微元、shopspring/decimal、Gin/GORM、React/Recharts，不新增依赖。保留原始 snapshot 字段及其金额，新增独立 current-rate historical estimate 字段和计数，显示总估算=有效历史快照+明确标注的历史回算。历史只读，不写回数据库。仅 exact channel_id + recorded upstream_model == CostRateModel 且有效价格、已知用量时回算；不按模型名猜连接。无缓存明细时用普通输入价，注明估算口径，不能把 cache_usage_known 变真。无证据记录保持未知；已有有效快照优先，后改价格不能改写它。

比较：只显示未来调用最省改动但无法解决当前金额诉求；回写历史快照会伪造当时单价，不采用；推荐只读历史回算与快照分开展示。

界面：显著今日、本月、所选周期金额卡片；日/月视图切换（日近7/30天，月近12个自然月），每个桶汇总调用次数、输入输出Token、快照金额、历史估算、未计价次数，金额图表；保留原模型筛选、Token图及原始逐条用量。固定官方价不冒充自动分时/阶梯账单。
