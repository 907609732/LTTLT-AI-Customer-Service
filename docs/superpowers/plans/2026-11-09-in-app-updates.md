# 软件内下载并安装更新

用户要求在软件内下载后自动安装。沿用 electron-updater 6.x 与现有 GitHub/NSIS 产物，不引入新服务和依赖。

- [ ] 更新服务增加下载、进度、校验完成、安装与失败状态；用户点击后才下载，校验通过自动 quitAndInstall(true,true)。
- [ ] 同时操作只执行一次，下载或校验失败不安装，关闭软件或过期回调不安装；测试事件、异常与重试。
- [ ] 新增受可信窗口限制的 IPC，前端按钮改成下载并自动安装，展示进度与自动重启提示；浏览器只作为失败后的备用入口。
- [ ] 先写失败测试，再实现；执行类型检查、单元/后端/页面和 Electron 验证。
- [ ] 构建发布 v0.4.3；检查公开更新源及真实下载/校验链路，测试时拦截最终安装调用，避免覆盖用户正在使用的程序。

旧版 0.4.2 没有下载能力，需先安装一次新版本。保留原用户数据及现有应用权限。
