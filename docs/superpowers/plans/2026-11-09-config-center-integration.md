# 配置中心接入实施计划

**目标：**以现有 React/Electron 和经授权的云朵页面为参考，逐项接通可真实运行的配置中心功能。

**架构：**界面使用现有受信任渲染器；设置由 Electron 主进程校验、写入现有隔离数据目录，并由实际业务引擎读取。没有平台或服务支持的交互保留明确未接入状态。参考 `docs/CONFIG_CENTER_REUSE.md`。
