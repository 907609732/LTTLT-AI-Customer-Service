# 店铺侧栏与基础设置引导

用户已明确按参考截图实施：紧凑店铺行、平台图标、名称、真实在线状态与AI开关；移除行内三按钮，改右键菜单。保留基础设置、导入知识、店铺设置、店铺后台、关闭，不加入AI管理中心。导入知识/店铺设置本轮仅入口，点击明确提示后续接入；关闭只断开，不删除店铺资料。

复用现有Vue/ElementPlus2.8.8菜单/弹窗、平台图标、runtime命令与受限平台后台窗口，不增加依赖。已核对[Element Plus Dropdown](https://element-plus.org/en-US/component/dropdown)支持contextmenu，以及参考软件[帮助中心](https://zhikest.cn/help_center.html)的添加/知识/基础设置入口。只借鉴交互和布局，不复制第三方代码、品牌或账户资料。

基础设置为可反复打开的新手引导：连接店铺→商品/问答知识→接待配置与试答。各步复用现有配置页，真实状态来自本店快照。添加成功后自动显示；去登录时暂收起，连接成功继续知识步骤；去配置页后提供返回引导入口。完成或跳过不自动开启AI或修改真实接待设置。工作区变化/店铺移除后清理旧引导，异步操作检查租约。

分工：侧栏组件和交互测试；shops引导状态/弹窗/AddShopDialog及专项测试；统筹App/MainLayout接线、打开店铺后台受限命令和源码验收。现有hub为demo，不能直接作为后台功能冒充接通。后台窗口按店铺现有分区打开平台固定首页，校验店铺归属、来源和生命周期，不暴露任意URL。

验收：相关UI与引导测试、后台命令来源/店铺隔离、添加后自动引导、右键不触发登录/AI、占位明确、关闭保留资料、真实源码窗口视觉及菜单操作。不调用付费模型或向真实买家发送。

实现入口：`StoreSidebarCard`只发业务事件；`setup-store.ts`保存当前窗口的引导位置；`App.vue`挂载引导，`MainLayout`统一隐藏弹窗下的原生页。`open-store-backend`复用现有业务命令通道，不新增IPC；`electron/store-backend.ts`校验当前店铺及生命周期后，通过`assist-platform-host`打开固定首页。拼多多共用同店登录分区；抖店后台使用独立分区，明确提示核对登录。模拟及其他平台拒绝。

引导状态不持久化，关闭/跳过只结束引导；再次右键基础设置可重新配置。登录期间切换店铺取消旧引导，旧工作区/已移除店铺的晚到结果不再显示。配置页程序收起弹窗时保留“继续基础设置”，用户主动关闭才退出；实际Element Plus过渡事件已纳入回归测试。底部菜单仅回退到`top-end`，不向右覆盖原生平台区。

定向测试41项通过，范围为侧栏、引导/添加店铺、布局接线、后台入口及直接影响的平台列表窗口；没有运行全量Release检查。源码实店后台入口已核对到拼多多商家首页，AI保持关闭，未发送消息；抖店本轮仅验证固定入口/隔离逻辑，未进行实店登录验收。
