# 版本号与界面识别

1.0.54：GitHub README 增加灵兔套件项目互链；保留 1.0.53 主线功能，未发布新安装包。

用户要求每次交付修改更新均增加版本号，防止启动或安装错版本。

package.json是版本号唯一来源；Vite构建时注入版本，由共享AppVersion组件在主工作台和配置中心左下角显示。源码开发时修改版本后重启开发服务，已运行的旧实例不会显示未来版本。

每批交付更新一次版本：修正使用patch（例如1.0.1→1.0.2），同步锁文件，使用 `npm.cmd version patch --no-git-tag-version`；功能及兼容性变化按实际范围选择minor或major。常规编辑单个文件不重复增加，同一次交付的修订和验证共用该版本。

随后构建并验证版本显示，打包文件名、app版本和发布tag一致。已有公开版本附件不可覆盖，发布新版本另建tag。当前桌面源码版本以 package.json 为准；当前运行窗口版本须以实际显示为准，不能用源码版本冒充已重启。托管服务部署记录见 HANDOFF.md。公开v1.0.1保持原样。单纯记录同一批版本的部署回执不再重复增加版本号。
