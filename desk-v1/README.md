# desk-v1 · 多平台店铺同屏客服工作台

一个 Electron 桌面应用，把多个电商店铺的客服会话放进同一个窗口管理，支持消息采集、日志、AI 辅助回复与人工接管。

## 支持的平台

| 平台 | 接入方式 | 状态 |
|---|---|---|
| 拼多多（网页版商家后台） | WebContentsView + 页面注入 | 可用，需扫码登录 |
| 抖店（抖店工作台客户端） | 外部客户端 + 本机桥接 | 可用，需客户端已安装并登录 |
| 闲鱼（网页版） | WebContentsView | 预留，尚未启用 |

## 功能

- 多店铺同屏托管，每店独立 Electron session 分区，登录态互不干扰
- 消息实时采集与桌面日志（买家显示昵称，我方显示「我」）
- AI 回复引擎：支持任意 OpenAI 兼容端点，默认关闭，需手动开启
- 人工抑制：客服手动回复后 AI 不介入；可配置关键词触发接管
- 发送台账去重：msgId 精确匹配 + 8 秒文本兜底，避免把自己的消息当成买家消息
- 发送节奏控制：同会话最小间隔、随机抖动、单店每分钟上限
- 会话存档与漏回统计，断线重连后限时补回
- 抖店客户端一键重启（关闭并重新拉起客户端后自动重连）

## 快速开始

```powershell
npm install
npm start
```

1. 在左侧输入店铺名称并选择平台，点「添加」。
2. 拼多多店铺点「打开」，在弹出的商家后台扫码登录。
3. 抖店店铺确保「抖店工作台」客户端已安装并登录，点「打开」或「重启」。
4. AI 默认关闭；需要自动回复时在设置中填写 baseUrl / model / API Key 并手动开启该店铺的 AI。

## 配置与数据

- 配置位于 Electron 用户数据目录下的 `config.json`（Windows 为 `%APPDATA%\desk-v1`）。
- AI API Key 通过 Electron `safeStorage` 加密保存，不写入配置文件。
- 会话存档同样位于用户数据目录；日志默认 8MB 轮转。

## 测试

```powershell
npm test              # 单元测试
npm run selftest:hook # 页面注入与适配器的离线自测
```

## 设计边界

- 本项目不包含、也不分发任何第三方客户端的修改工具。
- 抖店连接失败时，界面显示通用连接错误，请确认客户端已安装并登录后重试。
- 本机桥接服务只监听 `127.0.0.1`，方法白名单，无任意表达式执行通道。
- AI 默认关闭，避免在未配置端点时向真实买家发送任何内容。

## 目录结构

```
src/main/        主进程：窗口、配置、存储、日志、回复引擎、平台服务
src/adapters/    各平台适配器（契约见 src/shared/adapter-contract.md）
src/injections/  页面注入脚本
src/renderer/    控制台界面
test/            单元测试与离线 fixture
scripts/         启动与离线自测脚本
```
