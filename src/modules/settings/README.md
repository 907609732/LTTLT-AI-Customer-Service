# settings 模块

职责：登录与供基础设置复用的回复间隔控件。公开入口为 index.ts。

“充值”入口统一放在登录弹窗右侧服务端标题旁，点击进入原/shop/recharge页面后关闭弹窗；配置中心不再显示充值按钮。仅导航，不发起支付或自动切换账号。

主页登录/账号弹窗的服务端区统一展示总额度、剩余额度、额度到期时间，以及“我的订单”“算力消耗”入口。期限取account.trial.expiresAt（秒），未提供不推断。详情经billing公开入口复用compact账本组件；关闭或切身份时清除，同身份额度刷新不误关。配置中心不再重复展示账户账单菜单。

顶栏唯一 LoginDialog 登录入口复用 Element Plus、model-presets 与 runtime.run。自己的 Key 连接验证成功后保存；错误保留输入，关闭清空草稿。服务端采用已有浏览器设备授权，明确取消才停止授权；登录成功经 activate-model-source 安全切换工作区后关闭，失败不冒充可用。账号名、剩余次数、切换账号与退出保留。

2026-11-15：左下角设置入口及独立设置路由已移除，旧/settings地址跳转配置中心。高级模型配置页面退役，模型密钥仍经顶部登录弹窗维护。ReplyPacingSettings 由基础设置的客服风格页复用现有REPLY_PACING命令与expectedMs并发检查，独立明确保存，全局作用于所有店铺同一买家。默认/最小为1秒，上限3600整数秒；主进程保存入口拒绝0。首次工作区升级将旧默认60秒和低于1秒值改为1秒，保留其他自定义值；reply-pacing-v2标记避免重复覆盖用户后来主动保存的60秒。

验证：tests/simple-login.test.ts 覆盖设置简化、Key失败保留、成功关闭、关闭不取消授权及授权后的工作区切换。真实账号与模型调用未由夹具测试证明。GeneralPanel 保留旧还原视图，未接线。
