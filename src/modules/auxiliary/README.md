# auxiliary 模块

职责：辅助中心、会话预览、后台聚合、助手与弹层。

买家消息日志附带逐条 AI 处理状态、调用事实及原因，可跳转请求和显式恢复被暂停会话；历史无证据不能倒推。处理规则见 docs/MESSAGE_AI_STATUS.md。

RuntimeLogsView 是独立日志窗口：已采集的店铺/买家/客服消息、实际模型上下文及候选确认。经模块入口导出，由主进程窗口加载 /logs；状态机、失效和发送闸门在主进程，不允许 UI 自行发送候选文字。见 docs/RUNTIME_LOGS.md。

公开入口：index.ts。跨模块必须从该入口引用，禁止访问 components 或 demo 的内部路径。

界面入口：AiAssistCenterView、MascotFloatView、SnapOverlayView、ConsultPanel、BackendHubView、HubTabBar、HubWebStage。

当前业务状态：AiAssistCenterView 已接采集会话、选择/定位、人工发送、草稿和恢复本会话 AI。其他聚合/助手还原组件尚未承担真实业务；平台真实性需用户验收。

2026-11-14 辅助中心恢复为 300px 竖向浮窗：咨询待回/已回、真实人工预警、客服工单状态/跟进、原问题纠错、快捷话术和发送均复用现有运行时。选择和发送按店铺/顾客/工作区隔离；发送不确定保留草稿，确认关闭先保存本窗全部有效已编辑草稿，失败留窗。清除只隐藏已回复显示，不删除归档；工作区变化清空筛选及所有业务草稿。Ctrl+Tab 仅处理面板内按键，Enter 发送、Shift+Enter 换行，输入法组词不发送。

窗口行为经 shared/platform 的受限接口接入；预览页面不得关闭整个应用。声音默认关闭，首次快照、首次平台成功同步与提醒设置变化只建立基线；同一事项版本不重复播放。渲染页每 5 秒读取平台快照，实际 60 秒只读采集由主进程统一调度，未读取/失败不得冒充零条。平台工单和售后须以真实店铺只读验收结果为准，不因 UI/夹具通过宣称全部接通。

本轮优先复用项目已有平台图片和图标、Element Plus、话术库，不引入新依赖。提示音使用本机 Figma 原图导出的 `src/assets/assist-sound-figma.png`（UX26、声音图层8801:2841、25×26），不是截图裁切；临时导出设置已移除。MCP额度限制仍影响完整结构化设计导出，不能因此宣称所有状态已像素级验收。日常仅跑辅助中心及直接影响的测试/类型/文件静态检查，Release 才做全量。

接入流程见根目录 docs/LOCAL_INTEGRATION.md。demo 是旧视图数据，不是 API DTO；新增能力在所属模块建立服务与类型，经过本地运行时契约，不直接访问 IPC、网络或文件系统。
