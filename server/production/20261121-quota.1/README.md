# 2026.11.21-quota.1 对应补丁

实际生产升级记录见 [部署验收](../../DEPLOYMENT-20261121-QUOTA.md)。此目录保留已部署候选的精确来源补丁和操作脚本，不代表把当前主干全部功能部署到了线上。

- `production-only.patch`：以生产 SOURCE 归档中的 `project/server` 为基底，仅增加新套餐额度、账号批量试用调整和保留宽屏排版；从 `project` 目录以 `git apply --check production-only.patch` 检查后应用。
- `release.json`：构建时的候选来源、产物摘要和实际验证范围；其中“尚未部署”描述封装时状态，当前状态以部署记录为准。
- `deploy-quota.py`：本次实际审核并执行的 Linux 部署脚本，含固定旧基底与唯一 release 名。不是可重复初始化的通用脚本；已部署目录存在时会拒绝再次 stage。凭据、业务数据库、环境文件和构建产物均不在仓库。

对应完整 SOURCE 保存在新 release 中，含固定 New API 上游、覆盖源码、锁、许可和构建入口。二进制与网页由同次候选构建产生，完整摘要在 `release.json`；不要以另一工作树重新构建的不同产物替换它并沿用本次回执。

脚本中响应 HTML 忽略注释比较，是为兼容原生启动时的 analytics 注释替换；文件、源码归档、完整网页树和实际提供的后台 JS 仍做精确摘要检查。数据库指纹忽略既有启动运行字段、Casbin 自增 ID、额度锁计数和新生成的模型更新任务；客户字段、账本与旧任务仍受保护。
