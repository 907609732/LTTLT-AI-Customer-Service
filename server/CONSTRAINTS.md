# 服务端约束

1. 来源固定为 LTTLT-AI-Customer-Service 的 codex/managed-admin-real-ui-20261113，提交 fd45e3832f3cceefefa64f8ff43d05da2cffe5e9。New API 上游固定提交见 upstream.lock.json，不跟随浮动最新版。
2. server 与桌面独立构建；不覆盖 Vue 前端、桌面数据或生产服务。导入的 Go/React/JS 保留来源和许可，目录不是桌面类型/静态检查的规避通道。
3. .upstream 是准备脚本生成的源码目录，不能直接修改后冒充覆盖层；修改写入 overlay 或有精确锚点的 patches.json，再重新准备。
4. 数据库、主密钥、会话密钥、生产环境文件、凭据、聊天原文、构建产物不提交。测试使用临时数据库和模拟模型，不使用正式账号或付费模型。
5. 保留管理员验证、请求去重、事务账本、未知结果占用与审计。不得通过重试模型调用做对账，不把未知 Token 用量视为零。
6. 密钥只在服务端加密保存，客户端只持有受限会话；日志和快照不得携带密钥。服务端数据库与主密钥必须按既有运维约束一起备份。
7. 生产使用 HTTPS、受限来源和回环监听；本机测试可使用隔离回环服务，不能将测试入口发布公网。
8. 28 类配置支持不等于全部真实厂商验收；未配置登录方式、支付和海外部署不得冒充完成。

9. 用户明确要求本机 HTTP 预览：只在 LINGTU_LOCAL_HTTP=1、LINGTU_LISTEN_HOST=127.0.0.1、API/portal 同为带端口的 http://127.0.0.1 且关闭 Secure cookie 时允许。独立 peer/Host/Origin 守卫拒绝非回环和跨站请求；不创建证书，不开放公网。远程服务保留 HTTPS 约束。
