# 云朵客服 Windows 预览包

分支：codex/yunduo-managed-desktop-release-20261114。

本版将云朵 Vue/Electron 客服前端、80 条精选通用客服话术、可选托管账号与额度接入，以及独立 server 源码整理到同一工程。保留本机 Key、聊天历史上下文、16K/8K 压缩、实时诊断、模拟客服台和逐条确认发送。托管来源或账号切换要求重启，按来源/账号隔离数据；本机 HTTP 调试只允许带端口的 127.0.0.1。

Windows x64 安装程序与 ZIP 由 GitHub Actions 对本次源码提交构建。发布步骤在类型/静态/来源校验、项目单元与上游回归、真实 Electron 桌面验收及打包后程序验收全部成功后执行。RELEASE-MANIFEST.json 记录源码提交与云端构建地址，SHA256SUMS.txt 用于核对下载内容。

使用安装程序完成当前用户安装，或解压 ZIP 后运行 YunduoCustomerService.exe。首次打开默认本机 Key，AI 不自动开启；需要托管服务时在设置中配置地址并授权。管理服务独立运行，不包含在桌面包中，本机后台不会随安装包分发。现有管理员密码、数据库、主密钥和店铺登录资料不在安装包及源码中。

这是无代码签名的预览版本；没有自动更新，不改变已有稳定版发布渠道。真实厂商模型、线上 OAuth/SMTP、生产部署和真实买家发送不属于此包自动测试声明。服务端运维见 server/README.md，客户端维护见 AGENTS.md、docs/CONSTRAINTS.md 和 docs/PACKAGING.md。
